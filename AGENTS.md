# Instrucciones del proyecto biblioteca

## Situación actual

El usuario autoriza expresamente implementar toda la evaluación el 9 de noviembre de 2026. Aplicar la spec previa y el perfil del agente para desarrollar y verificar backend/frontend. Las capturas del usuario se incorporan al README cuando estén disponibles; no inventar evidencia visual.

## Referencias obligatorias

- Leer `.agents/features/reserva-libros.md` antes de implementar o modificar funcionalidades.
- Aplicar el perfil de desarrollo `.agents/subagents/biblioteca-developer.md` cuando comience el trabajo autorizado. Registrar su uso real; no afirmar que crear el archivo equivale a ejecutarlo.
- Se usa `.agents/features` y `.agents/subagents` para seguir las carpetas de los ejemplos del profesor.

## Reglas

- Mantener backend/frontend separados, con el estilo y las capas del curso.
- Los originales del profesor, fuera de esta carpeta, son de lectura y no se ejecutan ni modifican.
- Crear primero la spec del cambio y documentar los resultados después de verificarlo.
- No incorporar funciones opcionales sin decisión explícita.
- No almacenar credenciales en Git ni probar contra bases de otros proyectos.
- Preparar el README final en presente cuando la aplicación funcione y se compruebe cómo ejecutarla.
- La publicación del repositorio y el envío de la entrega requieren autorización del usuario.
